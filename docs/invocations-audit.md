# Инвокации жреца и контраст карточек

Дата: 2026-10-05. Версия системы остаётся 0.2.0.

## Реализовано

- Исправлен цвет значений дистанции, длительности и защиты. Явный тёмный цвет перекрывает светлое оформление Foundry для `dd`, включая живой каталог.
- Добавлены 28 инвокаций: 11 друида, 11 проповедника и 6 верховного жреца. Общий каталог содержит 93 записи. Инвокации сгруппированы по традиции и уровню внутри существующего компендиума «Заклинания».
- Во вкладке «Магия» и каталоге появился фильтр традиции. В карточках показаны божества верховных инвокаций. Поиск также находит по божеству. Редактор поддерживает традицию, божество, альтернативную дистанцию «на себя / N м», защиту ВОЛЯ × 3 и длительность в днях.
- Стоимость «Проклятой болезни»: только 2, 4 или 6 ВЫН. «Дар природы» принимает положительную целую стоимость. Фокус применяется после выбора стоимости. Неправильное значение не создаёт бросок и не расходует ресурсы. Рассеивание сохраняет прежнюю переменную стоимость.
- Инвокации используют общие броски, Удачу, расход ВЫН, предел за раунд, поддержание и ожидание Dice So Nice. Стихийные последствия инвокаций — смешанные, выбираются ведущим. Длительность в днях использует существующий форматтер чата и не тратит Удачу.
- Создание собственной магии у жреца по умолчанию создаёт инвокацию; традицию можно изменить в параметрах Item.
- При обновлении страницы активным ГМ недостающие записи добавляются через Foundry API. Миграция сохраняет пользовательские описания, существующие идентификаторы, импортированные копии и блокировку компендиума. При занятом ID выдаёт ошибку вместо перезаписи; после сбоя допускает повтор.

## Источники и неоднозначности

- Предоставленный PDF `doc398595855_579050583.pdf`, печатные страницы 109–114 просмотрены визуально. Инвокации заканчиваются на 113; на 114 начинается отдельный раздел ведьмачьих знаков, который в этот блок не включён.
- Сверено с текущим файлом [официальной errata v4](https://rtalsoriangames.com/wp-content/uploads/2022/03/RTG-WI-WitcherCoreErratav4.pdf) со [страницы издателя](https://rtalsoriangames.com/errata/): защиты, 35% у «Песни небес», расчёт «Благословения удачи», спас через ИНТ у «Паутины лжи», лечение обработанных критических ранений у «Целительного покоя».
- «Благословение любви»: текст указывает получателем заклинателя, а дистанция равна 5 м. Сохранены оба указания книги. Конкретного официального уточнения в поиске Sage’s Answers не найдено; оставлен TODO, выбор цели остаётся у ведущего.
- Временные очки двух инвокаций Удачи описаны отдельно от постоянной характеристики. Автоматического изменения обычного запаса нет: без модели временных эффектов это перезаписывало бы исходную Удачу.
- Маги не изучают инвокации по базовым правилам; это указано в каталоге. Добавление в книгу означает внесение уже изученной магии, а не автоматическую проверку обучения, веры или ранга жреца.

## Аудит архитектуры

- Duplicate-check: использованы существующие Item `spell`, Actor `magic`, компендиум `spells`, ItemSheet, карточки, фильтры и общий процесс сотворения. Новых типов Actor/Item и отдельной базы инвокаций нет.
- Каталог данных разделён на магические заклинания и инвокации, но преобразование в Item и папки общее. Старые 65 ID и папки сохранены. Для старых Item традиция по умолчанию `mage`.
- Шаг/максимум переменной стоимости структурированы и проверяются общей функцией до списания. Правила стоимости не разбираются из текста описания. Нет второго хранилища изученной магии или ресурсов персонажа.
- Базы LevelDB работающего мира не открывались и не пересобирались. Обновлены JSON-источники; добавление контента работает через идемпотентную миграцию активного ГМ.

## Проверки и оставшееся

- 217 unit-тестов; `npm run check`; установленный Foundry 14: 896 документов, схемы и шаблоны, старые/новые данные и повторная сериализация. Проверена нотация девяти цепочек d10 установленного Dice So Nice.
- Добавлены проверки 28 инвокаций, уникальных ID/папок, переменной стоимости, фокусов, поддержания без Удачи, смешанного провала, безопасного повторения миграции, сохранения изменённых описаний и блокировки после ошибки.
- В живом мире открыты старый лист Виктории и каталог, проверен контраст раскрытого «Зеркала Афана». Новых ошибок системы в консоли нет; присутствовали только предупреждения Foundry о размере окна. Данные персонажа и чат не изменялись.
- На локальном предпросмотре настоящего шаблона и CSS проверены фильтр проповедника/верховного жреца, отображение божества, «1 день» и раскрытие карточки. Снимки: `.dev/magic-contrast-fixed.png`, `.dev/invocations-preview.png`.
- Для загрузки новых записей в текущий мир активному ГМ нужно обновить страницу. Создание нового живого персонажа, добавление/drag-drop инвокации и её сотворение на сервере этим клиентом не проверены: доступен игрок, а активная сессия ГМ не прерывалась. Сохранение/переоткрытие покрыто проверкой нативных моделей Foundry.
- Автоматизация индивидуальных эффектов по целям, временной Удачи, лечения ранений, аур, порталов, погоды и големов не добавлена; карточки содержат механику для разрешения ведущим. Это расширение существующей системы сотворения, а не отдельная реализация боя по целям.
