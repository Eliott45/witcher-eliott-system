Итого: 97 строк, 32 новых чертежа, один исправленный состав. Все соответствующие
предметы уже существовали; новые экземпляры результатов или материалов не создавались.
UUID компонентов и результатов ведут к существующим записям, поэтому работают
«Как изготовить» и «Используется в» с ранее добавленными цветами и сортировкой.

Нильфгаардский шлем по стр. 135: тёмная сталь ×5, масло ×5, укреплённая кожа ×1,
чернящее масло ×1, масло из дрейка ×1, пепел ×10. Его СЛ, время, доплата и цена не менялись.
Необычные печатные цены сохранены: например, оба чертежа боеприпасов на стр. 137
стоят 100 крон, а доплата составляет 184 и 185 крон соответственно. Доплата
не вычисляется из цены чертежа или готового предмета.

Добавлен уровень `grandmaster` («Великий мастер») в схему, редактор и карточку.
Он сохраняет требование изученной «Мастерской работы», действующее для мастерских
чертежей; отдельный неподтверждённый порог уровня способности не вводился.

Миграция содержания 17 при входе активного ГМ добавляет отсутствующие чертежи в
каталог через API Foundry. Совпадение определяется по `ruleId`: пользовательская
копия под другим ID не дублируется. Старый состав шлема заменяется только при полном
совпадении прежних компонентов; изменённые составы, цена, время, доплата, название и
запоминание сохраняются. Исправление охватывает каталог, предметы мира, персонажей,
несвязанные токены и прегены. Старые ID всех 596 записей сохранены. Напрямую живая
LevelDB не изменялась, обновлён JSON-источник каталога. Версии манифестов не менялись.

Проверки: 434 теста; наличие связей для всех 97 строк; точный расход компонентов
и выдача партий 10/5 боеприпасов; идемпотентность миграции и сохранение пользовательских
правок; проверка прежних ID; нативные схемы для 992 документов и шаблоны установленного
Foundry; синтаксис, манифесты и соответствие JSON-источников генератору.
Проверка в запущенном игровом мире не проводилась.
