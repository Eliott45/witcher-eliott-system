Пять школ, принятие в обучение, тренировки, испытания, важное событие и нынешнее положение представлены раздельными значениями. Предметы и денежные награды автоматически не выдаются, как было согласовано для Lifepath.

Веса/цены для позиций без указанной доступности не дополняются выдуманной редкостью. [Sage’s Answers Finale](https://rtalsoriangames.com/2018/10/12/the-sages-answers-finale/) проверен для разграничения щитов и брони. Автоматическое снятие надёжности от попаданий/блоков и применение эффектов оружия пока относятся к будущему боевому действию; здесь хранятся их реальные параметры.

Каталог дополнен 35 видами оружия, 8 щитами, 27 доспехами, 47 предметами/инструментами. Это базовые таблицы обычного оружия и брони; специальные эльфские/краснолюдские/ведьмачьи позиции, алхимия и улучшения добавляются следующим блоком, а не выдаются как уже полный каталог книги.

Количество, вес единицы, цена, доступность, принадлежность к носимому имуществу, надевание, особенности и источник доступны в Item. Состояние оружия и брони ограничено максимумом. Вес Actor вычисляется из носимых физических Items; старое ручное значение веса не используется. Компаньоны не увеличивают переносимый вес. Кроны хранятся одним числом в Actor. Добавление из каталога не означает покупку и не списывает деньги.

Audit архитектуры: физические типы наследуют один совместимый equipment, с отдельными схемами оружия/брони. Надетое хранится только в Item, Actor не содержит копии экипировки. Поле layer и вычисление списка по зонам позволяют позже поддержать слои без миграции; нынешняя кнопка заменяет предмет той же зоны/слоя. ПБ не складываются самовольно. Базовые значения не перезаписываются бонусами. Общее окно поиска расширено входными данными для каталога, а не скопировано. Последующая установка улучшений будет отдельным источником изменений.

Проверки: 100 unit-тестов, check, сборка всех компендиумов, проверка 348 Items установленным Foundry. Harness проверяет старые предметы, сериализацию экипировки/повреждений, вес и EV. В мире старая Виктория открыта без изменения данных; создан QA — Инвентарь. Перенос гамбезона из компендиума действительно завершился (native drop сохранил его ID); второй экземпляр добавлен через поиск. Надевание, изменение ПБ и отсечение значения выше максимума проверены. Рабочие действия:

- Покупка материалов списывает кроны; добавление через каталог по-прежнему бесплатно.
- Создание предварительно показывает СЛ, компоненты, время и доступ к инструментам/кузнице.
  Физический рецепт даёт +2. Точные компоненты резервируются раньше субстанций, чтобы одна
  порция не оплатила два требования. Для субстанций выбираются самые дешёвые подходящие
  ингредиенты; фактический выбор виден до подтверждения. При провале материал расходуется,
  затем предлагается немедленная попытка спасения компонентов по правилам.
- Ремонт восстанавливает текущую надёжность/ПБ до максимума с установленными улучшениями.
  Требуется по одной единице каждого компонента; СЛ чертежа −5, +2 за руну/глиф/усиление.
  Полный ремонт не превращён в пропорциональную оплату за каждый восстановленный пункт:
  Sage 12 отличает его от профессионального «Быстрого ремонта».
- Руна/глиф расходуются после явного подтверждения постоянности. Усиление брони требует
  полного раунда и проверки Изготовления СЛ 14; снятие — СЛ 15. Остаток комплекта сохраняет
  доступные зоны. Модификации ремесленника отделены от этих слотов, одинаковые не повторяются;
  предусмотрены шесть модификаций, инструменты, бонус кузницы и повреждение при провале.
- Масло расходуется на конкретное оружие, не занимает слот, заменяет предыдущее покрытие.
  Расчёт oilDamage возвращает +5 только для совпавшей категории и до истечения 30 минут.
  Истечение использует игровое время и работает также для несвязанных токенов.
- NPC хранит структурированные строки добычи. Попытка извлечения однократная; мутаген по
  умолчанию требует Подготовку ведьмака СЛ 16. Подготовка одной порции занимает час с
  проверкой Алхимии соответствующего мутагена; её может выполнить выбранный доступный союзник.
  Подготовленная порция применяется только ведьмаку с одним из двух свободных слотов.
  Постоянный источник записывается в mutations, а не во временные Active Effects.

Audit архитектуры: общие конструкторы полей вынесены в item-fields, чтобы наследуемые
физические типы не зависели циклически от рецептов. Бонусы установок и мутагенов вычисляются

одно изменяемое значение; ограничение применяется после суммирования всех улучшений.

transaction с компенсацией при ошибке записи. Это защита от двойного нажатия в одном клиенте,
не распределённая серверная транзакция между двумя одновременно работающими владельцами.
Для такой совместной правки ещё нужна серверная сериализация — TODO будущей сетевой доработки.
