# Материалы и собирательство

Источник: предоставленный пользователем PDF, печатные страницы 128–129. На странице 128 проверка сбора — Выживание против СЛ материала; персонаж должен находиться у подходящего источника. При успехе получают указанное количество единиц. Продолжительность определяет ведущий.

- У 22 материалов страницы 128 появились короткие описания. Для всех уже существующих материалов и ингредиентов динамически отображаются место получения, СЛ, количество из источника и проверка. Эти сведения читаются из полей предмета, поэтому изменения в редакторе сразу видны в описании, раскрытом инвентаре, каталоге и карточке чата.
- У стекла, шёлка, коровьей шкуры и лирийской кожи исправлено получение на «Покупается». Кости животных получают от чудовищ и животных. У пятой эссенции указан источник со страницы 129: места силы, маги и бесы. Цены, вес, количество в инвентаре и пользовательские заметки сохраняются.
- Макрос «Собирательство (ГМ)» в компендиуме макросов вызывает `game.system.api.forage()`. Запуск и выдача доступны только ГМ. Выбор материала поддерживает поиск по названию/местности. Покупаемые/изготавливаемые материалы не включаются в природный сбор.
- Получателем может быть персонаж/NPC мира или отдельный несвязанный токен на текущей сцене. По умолчанию предлагается выделенный токен. Ведущий задаёт время, подтверждает источник и при необходимости меняет СЛ/количество. Для добычи без СЛ проверка автоматически не придумывается; неизвестное количество требуется указать.
- Проверка использует общий механизм Выживания с критами, Удачей и приватностью броска. После успеха количество определяется обычными кубиками без критов и Удачи. Дробные результаты округляются вниз, как в существующей системе добычи; это правило явно показано в окне. Нулевой результат не создаёт пустой предмет.
- Время поиска отражается в чате; глобальное время мира не перематывается. Отменённый бросок, недоступный источник, смена прав или повторное нажатие во время незавершённой проверки не выдают материал.
- Данные компендиума обновляются через штатную миграцию Foundry при входе активного ГМ (внутренний номер данных 15). Системная версия остаётся 0.2.0. Живые базы компендиумов внешними инструментами не изменяются.

Проверки: правила сбора, количество, отмены, права ГМ, приватность, повторные запросы, различение токенов, безопасная миграция старых описаний; нативные схемы предметов/макросов, строгая компиляция шаблонов и формулы кубиков установленного Foundry. Живая UI-проверка не выполнялась по просьбе пользователя.
