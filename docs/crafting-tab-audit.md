# Ремесло на листе персонажа

Источник: предоставленная пользователем базовая книга, печатная страница 127.

- Новая вкладка «Ремесло»: поиск, чертежи/формулы, отдельные группы запомненных рецептов, физических копий и недоступных записей. Видны СЛ, время, количество результата, итоговая база проверки, материалы и инструменты.
- Чертежи и формулы делят лимит памяти, равный Интеллекту. Повторные экземпляры одного рецепта занимают одно место. Запись из каталога создаётся с количеством 0 и без переносимого веса. Потеря физической копии (количество 0) не стирает запоминание; «Забыть» снимает его со всех экземпляров.
- Изготовление использует обычную проверку `1d10wc + РЕМ + Изготовление`, физическая копия даёт +2. По памяти бонуса нет. Алхимические формулы используют существующую проверку Алхимии. Результат берётся после штатного разрешения критов/Удачи.
- Для чертежей списываются конкретные материалы. Инструменты и кузница проверяются по требованиям рецепта; можно подтвердить доступ к мастерской. Перед броском игрок подтверждает, что время работы прошло; время мира не перематывается.
- Материалы тратятся при успехе и провале. Готовый предмет выдаётся только при успехе. Запасы, рецепт, доступ к физической копии и инструменты повторно проверяются перед записью. Повторное открытие изготовления тем же клиентом до завершения операции запрещено.
- Сразу после провала предлагается одна переработка с той же СЛ. Успех возвращает половину каждого материала, округляя вверх, один раз на вид компонента, независимо от количества стопок/строк. Существующее алхимическое спасение одной чистой субстанции сохранено. Результаты и расход/возврат публикуются с текущей приватностью бросков.
- Частичное создание результата отменяется с восстановлением материалов. Копирование физического рецепта не переносит память прежнего владельца.

Проверки: тесты изготовления, отмены, переработки, памяти, нехватки/изменения запасов и частичной записи; нативные схемы и строгая компиляция шаблона установленного Foundry, включая режим наблюдателя. Живая UI-проверка не проводилась по просьбе пользователя. Версия системы не менялась.
