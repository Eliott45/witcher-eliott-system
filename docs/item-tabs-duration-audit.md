# Item tabs and readable durations — 2026-10-04

All Item types reuse the existing WitcherItemSheet and Foundry ApplicationV2 native tabs: Description first, Details for physical/ability fields, Actions for workshop controls. Empty tabs are omitted. Existing field names, submit-on-change, read permissions and data models are retained; Details also has an explicit Save button. No duplicate Item or Actor structures. Armor workshop condition displays only SP; weapon/shield condition displays reliability.

Effect durations share one formatter between actor effect cards and duration chat results. Up to ten rounds remain rounds; longer durations use minutes, then hours at 60 minutes and days at 24 hours. Conversion uses the system's existing three-second round. For example, eleven rounds are 0.55 minutes and 36000 seconds are 10 hours. This changes presentation only: original native Roll totals, dice animation, save scheduling and expiry data remain intact. New messages persist duration value/units in a flag; older system messages are recognized only by their duration prefix, skipLuck flag and a matching canonical effect formula. Hidden roll contents are not exposed.
