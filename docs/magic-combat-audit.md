# Магия в бою (стр. 166–168)

8 октября 2026 года. Версия системы остаётся 0.2.0. Уже было (см. `magic-audit.md`, `signs-rituals-hexes-audit.md`): Воля + Сотворение, Энергия и расход за раунд, перегрузка 5 ПЗ за пункт, магический провал и стихийные эффекты, фокусы, ритуалы с помощниками, обратная порча.

## Новое
- **Цели заклинания (стр. 168).** Выберите цели (T) и сотворите заклинание: на каждую цель появляется карточка «Заклинание → цель», которая использует проверку сотворения из сообщения выше (с Удачей, если её потратили). Цель защищается способами, указанными у заклинания: Уклонение (и смена позиции), Блокирование (против магии — только щитом), Сопротивление магии, Сотворение заклинаний (против Рассеивания). Дальше обычный обмен: место попадания, урон по броне, применение.
- Зона действия — выберите всех в зоне, каждый защищается сам. «На себя» карточек не создаёт. При магическом провале 7+ заклинание никого не достигает. Цели дальше дистанции заклинания пропускаются с предупреждением.
- Без защиты (или добровольная цель): «Не защищается» = срабатывает без магического провала (СЛ 0, без критических ранений). «Воля цели × 3» — СЛ из Воли цели. Если защиты есть, но цель не защищается — СЛ как у дистанционной атаки по неподозревающей цели.
- **Магические ранения (стр. 166):** критические ранения — у земли, воздуха, воды (физическая сила). Огонь и смешанная магия — без критов (решение по формулировке «ветер, осколки льда, камни»). Огонь наносит стихийный урон (сопротивление огню, уязвимость ×2).
- Магическая атака не использует таблицу провалов оружия: провал разбирается на карточке сотворения.
- **Требования к сотворению (стр. 167):** в карточке — слова и пассы (навык 1–6), только пассы (7–8), малые движения (9–10).
- **Двимерит (стр. 167):** −1 к Энергии за каждую единицу двимерита в пределах 5 м (свой и у токенов рядом, по количеству), касание (надетый двимеритовый предмет или состояние «Касается двимерита») — Энергия 0 и кнопка «Стойкость СЛ 16» на вкладке «Магия» с таблицей эффектов; тошнота накладывается сама. Ведьмаки — не адепты магии, не затрагиваются.
- **Прерывание ритуала (стр. 168):** на вкладке «Магия» (если есть ритуалы) кнопки СЛ 15 / 18 / 16.
